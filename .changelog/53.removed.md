Drop support for Python 3.9 (end-of-life since October 2025); the minimum supported version is now Python 3.10. Beyond the end-of-life, the 3.9 CI job had also started failing at environment setup: `pipx` could no longer install Poetry under 3.9 because a transitive dependency now uses `dataclass(slots=...)`, which is only available on Python 3.10+.
